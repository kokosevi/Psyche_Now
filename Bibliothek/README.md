# Bibliothek (nur lokal)

Inhaltliche Quell- und Kontextfiles (PDFs, Slides) für die Erstellung der
Website-Inhalte — z. B. Fachliteratur und eigene Arbeiten.

**Dieser Ordner wird bewusst NICHT nach GitHub/Netlify übertragen** (siehe
`.gitignore`). Grund: Das Material ist teils urheberrechtlich geschützt bzw.
persönlich und gehört nicht in ein veröffentlichtes Repo. Es dient nur als
Kontext beim Schreiben der Themen — der eigentliche Website-Text entsteht als
Markdown in `site/src/content/themen/`.
